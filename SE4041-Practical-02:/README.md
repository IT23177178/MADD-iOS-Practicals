## Final Challenge

The Student Performance Manager demonstrates the following Swift concepts:

- Storing student marks using a dictionary
- Assigning grades using a `switch` statement
- Displaying student names, marks, and grades
- Identifying students who passed
- Storing and displaying unique grades using a `Set`
- Calculating the class average
- Finding the highest and lowest marks
- Searching for a student using optional binding
- Counting the number of students who passed and failed
