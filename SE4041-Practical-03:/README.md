## Description

This practical demonstrates fundamental Swift programming concepts, including functions, optional value validation, tuples, closures, enumerations, structures, and classes.

The final challenge combines these concepts to implement a Student Management System that stores student details, calculates grades, displays student information, filters students by marks, extracts student names, and calculates the class average.

## Technologies Used

- Swift
- Xcode / Swift Playgrounds
- GitHub

## Final Challenge

The Student Management System includes:

- A `Grade` enumeration with nine grade categories.
- A `Student` structure with stored properties and a computed grade property.
- A method to display student details.
- An array containing five students.
- A `filter` operation to select students with marks of 50 or above.
- A `map` operation to extract student names.
- A `reduce` operation to calculate the total marks and class average.

## Expected Result

Using the five sample students provided in the practical, the total marks are 313 and the class average is 62.6.
